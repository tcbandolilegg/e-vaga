# App de Match de Repúblicas

## 🎯 Objetivo
Um marketplace para conectar estudantes que buscam vagas em repúblicas a administradores que precisam preencher essas vagas, utilizando uma mecânica de "Match" (curtidas mútuas).

## 🎨 Identidade Visual
- **Primária:** Ciano (#00C2D1)
- **Secundária:** Verde (#15803D)
- **Estilo:** Airbnb/Instagram (Feed visual e limpo)

## 🚀 Funcionalidades (MVP)
- Perfil rico para Estudantes (curso, faculdade, hábitos).
- Gestão de Vagas para Administradores.
- Sistema de Match Duplo para liberar chat.
- Selo de Verificação e Avaliações de moradores.

## 🛠 Stack Tecnológica
- Mobile: Flutter
- Backend: Supabase (PostgreSQL)
- Pagamentos: Stripe/Mercado Pago
